Everything you need to grab images

Built to work on any website.

Hover download button

Hover over any image and a ⬇ button appears. Right-click works too.

Finds the max resolution

Tries variants of the URL (strips size suffixes like _280) and downloads the largest one that exists.

Sees through overlays

Works through the transparent layers some sites stack on top of images to block saving.

Download all

Save every image on the current page in one go.

Network image gallery

Shows a grid of every image the page loaded —even the ones you never saw— with their real dimensions.

Respects signed URLs

Detects signed addresses so it never breaks the download on sites that use them.

Three steps, zero setup

Install and start grabbing.

Install CrabGrab

Add it from the Chrome Web Store. An icon lands in your toolbar.

Hover or right-click

The ⬇ button shows over any image, or use the "Download image" menu.

Get the big file

CrabGrab finds and saves the max-resolution version to your downloads folder.

Your privacy, untouched

CrabGrab does not collect, store or send any personal or browsing data. Everything happens on your device. No cookies, no analytics, no third parties.
